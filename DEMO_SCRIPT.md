# Hackathon Demo Script: Cognitive Companion

Follow these exact steps to demonstrate the end-to-end working AI Cognitive Companion application during presentations or live evaluations.

---

### Step 1: Open Application Home Screen
1. Launch the app in your web browser.
2. Observe the welcoming header: **"Good Afternoon, Margaret 👋"**.
3. Point out the primary quick action cards: **AI Chat**, **Cognitive Training**, **Memory Bank**, and **Daily Tasks**.

---

### Step 2: Test Long-Term Personal Memory Store
1. Click **"Start Conversation"** or navigate to the **Chat** tab.
2. Type or speak using the microphone button:
   > *"My daughter's name is Priya."*
3. The AI Companion responds naturally and displays a green badge:
   > **✨ Saved fact to Memory Bank!**
4. Click on the **Memory Bank** tab.
5. Verify that *"My daughter's name is Priya."* appears under the **Family & Friends** category.

---

### Step 3: Run an Adaptive Cognitive Training Exercise
1. Click on the **Cognitive** tab.
2. Select **"Memory Recall"** or **"Logical Reasoning"**.
3. Note the current difficulty level badge (e.g. **EASY**).
4. Read the question and select the correct answer.
5. Click **"Submit Answer"**.
6. Observe the instant score feedback ("Correct! 🎉") and notice that the adaptive difficulty scales automatically.

---

### Step 4: Test Semantic Memory Recall
1. Return to the **Chat** tab.
2. Ask the AI Companion:
   > *"What is my daughter's name?"*
3. The AI retrieves the stored memory and responds accurately:
   > *"Your daughter's name is Priya."*
4. Notice the **Retrieved Personal Memory** badge beneath the AI message showing the context used.

---

### Step 5: Test Automated Task / Reminder Creation
1. In the **Chat** input, type or speak:
   > *"Remind me to call Priya at 6 PM."*
2. The AI Companion acknowledges the request and displays:
   > **⏰ Added task: "Call Priya"**
3. Navigate to the **Tasks** tab.
4. Verify that *"Call Priya"* is listed under today's pending reminders with a due time of 6:00 PM.
5. Click the completion checkbox to mark the task completed.

---

### Step 6: Review Progress & Caregiver Dashboard
1. Click on the **Progress** tab to inspect the cognitive skill domain breakdown (Memory, Attention, Reasoning, Language) and weekly trend chart.
2. Click the **Caregiver View** button in the top navigation bar.
3. Show the caregiver portal overview displaying Margaret's task completion status, cognitive performance summary, and active wellness alerts.
